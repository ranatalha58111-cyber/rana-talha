======================================================================
                  J.A.R.V.I.S. DESKTOP SUITE & APP
======================================================================

[1] HOW TO RUN JARVIS AS A DESKTOP APPLICATION:
    Double-click:  JARVIS.bat

    Yeh JARVIS ko direct standalone Windows Desktop App window mein
    open karta hai (Google Chrome ya Microsoft Edge ke native app mode
    ke sath, bina address bar ke).

[2] HOW TO RUN 24/7 BACKGROUND VOICE LISTENER:
    Option A: Double-click  run_silent_background.vbs
              (Silently background mein chalta rahega - 0 windows)
    
    Option B: Double-click  start_jarvis_background.bat
              (Live speech console HUD ke sath open hoga)

    Yeh background mein 24/7 mic se sunta rehta hai. Jab bhi aap bolein:
      "Jarvis yeh kaam karo [command]"
      "Hey Jarvis [command]"
    JARVIS fauran execute karega aur bol kar jawab dega!

[3] CREATE DESKTOP SHORTCUT:
    Double-click:  Create-Desktop-Shortcut.bat
    Yeh aapke Windows Desktop par JARVIS ka shortcut bana dega.

[4] TO STOP BACKGROUND LISTENER:
    Double-click:  stop_jarvis.bat
